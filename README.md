# Smart Café Admin App

Android app for café staff to manage the menu, work through incoming orders, read customer feedback and view sales analytics. The customer side is simulated so the admin side can be demonstrated end to end.

## Tech
- Kotlin, Android Studio
- Jetpack Compose (UI)
- MVVM with a repository layer
- SQLite through Room
- Own login built on a users table, with salted password hashing

## Project documents
- `docs/PRD.md` – requirements analysis and PRD
- `BACKLOG.md` – tasks mapped to requirement IDs and milestones
- `CLIENT_MEETINGS.md` – record of client (lab) feedback
- `CHANGELOG.md` – changes and change requests
- `GENAI_LOG.md` – log of any generative AI use

## Running the app
1. Clone the repo and open it in Android Studio.
2. Let Gradle sync.
3. Run on an emulator or device.
